## ✨ معرفی

**جامبو آزمون** یک سامانه کامل ساخت و برگزاری آزمون آنلاین است که به شما اجازه می‌دهد:

- فایل سوالات با فرمت `.q` آپلود کنید
- لینک اختصاصی برای دانش‌آموزان بسازید
- آزمون را با تایمر برگزار کنید
- نتایج را با نمودار و آمار کامل ببینید

همه چیز در **یک فایل پایتون** پیاده‌سازی شده و نیاز به تنظیمات پیچیده ندارد.

## 🚀 ویژگی‌ها

| ویژگی | توضیح |
|-------|--------|
| 📄 آپلود فایل `.q` | پشتیبانی کامل از سوالات تستی و تشریحی |
| 🔗 لینک یکتا | برای هر آزمون یک کد اختصاصی |
| ⏱️ تایمر زنده | با اتمام خودکار زمان |

| 💾 پایگاه‌داده سبک | SQLite (بدون نیاز به نصب جداگانه) |

## 📄 فرمت فایل `.q`

```text
&: نماد شیمیایی طلا چیست؟
*Au
-Ag
-Gd
-Go
#-
"""
نماد Au از واژه لاتین Aurum گرفته شده است.
طلا فلزی واسطه با عدد اتمی ۷۹ است.
"""
{
img:"https://example.com/images/gold.png";
}

&: آب از چند عنصر تشکیل شده است؟
-1
*2
-3
-4
#-
"""
آب (H₂O) از دو عنصر هیدروژن و اکسیژن تشکیل شده است.
"""

&: چرا طلا رنگ زرد دارد؟ توضیح دهید.
#-
"""
به دلیل ساختار الکترونی خاص اتم طلا و جذب طول موج‌های خاص نور مرئی.
"""
```

### قوانین فرمت

| علامت | معنی |
|-------|------|
| `&:` | شروع سوال |
| `*` | گزینه صحیح |
| `-` | گزینه غلط |
| `#-` | پایان گزینه‌ها |
| `""" ... """` | پاسخ تشریحی (برای نمره‌دهی تشابهی) |
| `{img:"url";}` | تصویر اختیاری سوال |

> سوالاتی که هیچ گزینه‌ای نداشته باشند به‌صورت **تشریحی** در نظر گرفته می‌شوند و بر اساس شباهت متنی (≥ ۷۲٪) نمره می‌گیرند.

```
۱. طراح ثبت‌نام / ورود می‌کند
۲. آزمون جدید می‌سازد (آپلود فایل .q + تعیین زمان)
۳. لینک اختصاصی دریافت می‌کند
۴. لینک را به دانش‌آموزان می‌دهد
۵. دانش‌آموز اطلاعات خود را وارد و آزمون را شروع می‌کند

```
